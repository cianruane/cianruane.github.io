# cianruane.com

Static personal website. No build step — plain HTML and CSS.

- `index.html` — home page (bio, photo, contact)
- `research.html` — research page
- `style.css` — all styling
- `images/cian.jpg` — headshot
- `cv/CianRuane_CV.pdf` — CV (add this file)
- `papers/*.pdf` — self-hosted paper PDFs (add these files)
- `CNAME` — tells GitHub Pages which domain to serve on

To update the site, edit the HTML files directly on GitHub and commit. Changes go live within a minute or two.
